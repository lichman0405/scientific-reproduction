# .development/ — Development Single Source of Truth

Live, recoverable state for the Scientific Reproduction v0.1 autonomous run (DEV-PLAN-V1).

| Path | Content |
|---|---|
| `plan.yaml` | Frozen Development Plan v1 (mirror of `development/development-plan.v1.yaml` + freeze metadata). |
| `milestones/` | One state file per milestone M0–M13 (status, gates, acceptance evidence refs). |
| `goals/` | One live state file per DEV-GOAL (status READY/WORKING/…/MERGED, attempts, reviews). |
| `attempts/` | Per-attempt records (worker, branch, worktree, commits, PR). |
| `results/` | Worker Result Packages. |
| `reviews/` | Independent Supervisor review records (PASS/REJECT/BLOCKED_HUMAN). |
| `events/` | Append-only development event log (bootstrap, freezes, defects, gates). |
| `gates/` | Human Gate registry (BLOCKING/PASSED). |
| `sessions/` | Supervisor session notes. Transient files under it are gitignored. |
| `dag-state.yaml` | Recomputed ready/blocked state of the goal DAG (regenerated by `scripts/state_summary.py`). |
| `KNOWN-DEFECTS.md` | Known spec-package defects and their dispositions. |

Rules (per `21-DEVELOPMENT-SUPERVISOR-SPEC.md` §5–6):

- `.development/**` is authoritative; Claude Code task state is only an execution mirror.
- The supplied `development/` is the frozen template source; `.development/` is live state.
- Only the Development Supervisor edits `.development/**`; it is committed on `main` as
  Supervisor-owned coordination state (never inside Worker PRs).
- `.development/sessions/` and `.development/tmp/` transient runtime data must not be committed
  (see root `.gitignore`).
